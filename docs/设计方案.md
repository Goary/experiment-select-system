# 实验选课系统 — 设计方案

## 1. 项目概述

面向高校的实验选课系统，支持三种角色：**超级管理员、教师、学生**。

核心业务闭环：

1. 超管维护账号（教师/学生）与基础数据（教室、实验室资源）；
2. 教师创建课程（实验模块），课程下创建多个**批次**（指定教室、上课教师、时间段、容量），发布后对学生开放选课；
3. 学生登录后先选课程、再选批次，选课结果进入个人课表；
4. 教师可导出学生选课信息（按教师维度、按 实验+批次+教室 维度）。

本期目标为**最小闭环**，架构与表设计预留扩展能力（签到、成绩、通知、冲突检测增强等）。

| 表 | 说明 |

|---|---|---|

**course_batch**
| 字段 | 类型 | 说明 |
|---|---|---|

| selected_count | int | 已选人数（冗余，防超选） |
| select_open | tinyint | 是否开放选课 |
| status | varchar(16) | draft / published / closed |

| 唯一约束 | uk(course_id, batch_no) | |

**batch_teacher**（批次授课教师，多对多，便于"具体上课老师"可以是多人/非课程创建者）
| 字段 | 类型 |
|---|---|
| id | bigint PK |
| batch_id | bigint FK |
| teacher_id | bigint FK→sys_user |
| uk(batch_id, teacher_id) | |

**course_selection**
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint PK | |
| student_id | bigint FK→sys_user | |
| course_id | bigint FK→course | 冗余课程，便于按课查询 |
| batch_id | bigint FK→course_batch | |
| select_time | datetime | 选课时间 |
| status | varchar(16) | selected / dropped（软删除，保留退课记录） |
| 唯一约束 | uk(student_id, course_id, status='selected' 业务保证) | 同一课程只能选中一个批次 |

> 说明：
> - **一个学生同一课程只能选一个批次**（业务约束，选课时校验）。
> - 时间冲突校验（学生维度、教室维度）本期做基础版：选课时检查学生已有批次时间段不重叠；教室冲突在创建批次时提示校验。
> - 所有表加 `deleted` 逻辑删除字段（MyBatis-Plus 支持）。

### 5.3 ER 关系

```
sys_user(教师) 1───n course 1───n course_batch n───1 classroom
                                      │ n
                            batch_teacher ── sys_user(教师)
                                      │ 1
sys_user(学生) n───n(经由 course_selection)─── course_batch
```

## 6. 核心业务流程

### 6.1 教师：课程与批次
1. 创建课程（编号、名称、简介）→ 草稿；
2. 课程下创建批次：选教室（**选定后自动带出该教室固定容量作为批次容量，只读展示**）、选授课教师（可多名）、设时间段 → 草稿；
3. 发布课程/批次 → `published`；
4. 开放选课（`select_open=1`）→ 学生可见可选；
5. 选课截止后关闭 → 查看名单 / 导出。

### 6.2 学生：选课
1. 浏览已开放课程列表 → 进入课程看开放批次（含教室、教师、时间、剩余名额）；
2. 选择批次提交 → 后端事务校验：
   - 批次开放中且未满（`selected_count < capacity`，行锁/乐观锁防并发超选）；
   - 该生未选过本课程其他批次；
   - 时间段不与其已选批次冲突；
3. 成功后 `selected_count+1`，写入 `course_selection`；
4. 退选：`status=dropped`，`selected_count-1`；
5. 「我的课表」：按时间排序展示已选批次（课程名、批次、教室、教师、时间）。

### 6.3 教师：导出
两种维度，输出 Excel（EasyExcel）或 CSV：
- **按教师**：该教师授课的所有批次 → 学生名单（学号、姓名、班级、课程、批次、教室、时间）；
- **按实验+批次+教室**：选定批次 → 该批次学生名单。

## 7. 后端接口设计（REST，统一前缀 `/api`）

统一返回体：`{ code, message, data }`，code=0 成功。

| 模块 | 方法 & 路径 | 角色 | 说明 |
|---|---|---|---|
| 认证 | POST /auth/login | 全部 | 返回 JWT + 用户信息 |
| 用户 | GET/POST/PUT/DELETE /admin/users | admin | 分页查询/增改删/重置密码 |
| 教室 | GET/POST/PUT/DELETE /admin/classrooms | admin | |
| 课程 | GET /courses/my | teacher | 我创建的课程 |
| 课程 | POST /courses, PUT /courses/{id} | teacher | |
| 课程 | POST /courses/{id}/publish | teacher | 发布 |
| 批次 | GET /courses/{id}/batches | teacher/student | 批次列表 |
| 批次 | POST /batches, PUT /batches/{id} | teacher | 创建批次（含教室、教师、时间；容量由后端取教室容量写入） |
| 批次 | POST /batches/{id}/publish /open /close | teacher | 状态流转 |
| 批次 | GET /batches/{id}/students | teacher | 选课名单 |
| 选课 | GET /student/courses/open | student | 开放选课的课程 |
| 选课 | POST /student/select/{batchId} | student | 选课（事务+防超选） |
| 选课 | POST /student/drop/{selectionId} | student | 退选 |
| 课表 | GET /student/schedule | student | 我的课表 |
| 导出 | GET /export/selections?by=teacher | teacher | 导出 Excel |
| 导出 | GET /export/selections?by=batch&batchId= | teacher | 导出 Excel |
